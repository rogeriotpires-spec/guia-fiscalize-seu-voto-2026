Como ler este resultado

Cada seção entra uma vez, com os números do boletim impresso pela urna. Todos os boletins somados aqui foram comparados com o TSE e são idênticos ao que foi publicado para a seção. Os boletins foram enviados voluntariamente por eleitores. Por isso este resultado não é uma amostra do país nem uma previsão: ele mostra o que diziam os papéis colados nas portas das seções que chegaram até nós.
